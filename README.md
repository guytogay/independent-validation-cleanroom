# Independent Validation Cleanroom — Legacy / Idle Infrastructure

Status: `IDLE / HISTORICAL_CONTENT_PRESENT / NOT_A_FRESH_BASELINE`

This repository is retained as reusable validation infrastructure and historical occurrence material. It is **not currently an active ENA experiment**.

The files and Git history in this repository contain prior `v0.3.7` validation context. Therefore resetting or replacing only the working-tree files does **not** make this repository a clean fresh-information surface.

## Current use rule

For strict fresh independent evaluation where prior experiment context could change the evidence, prefer one of:

- a new neutral disposable repository;
- a genuinely history-free/orphan-root experimental surface.

Do not tell a fresh evaluator that hidden source/oracle/history exists and then ask it not to inspect it. Remove the contamination structurally instead.

This repository may still be used when its historical context is harmless to the task, but that decision must be explicit.
