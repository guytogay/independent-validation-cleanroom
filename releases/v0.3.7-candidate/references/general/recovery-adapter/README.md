# Recovery Adapter — Optional Reference

Status: `v0.3.7 candidate.2 / GENERAL_OPTIONAL_REFERENCE / DEFAULT_OFF / NOT_NORMATIVE_ONTOLOGY`

Use when recovery reachability or post-restore world/authority reconciliation can change whether consequential work may resume.

Independent rescue and restore drills are conditional. Do not require them for every disposable or low-consequence recovery case.

Bundled contract, fixtures, and tools reuse the selected research reference bytes. The adapter consumes bounded Effect Lifecycle and Authority results rather than replacing them.

Key boundaries:

```text
CHECKPOINT_EXISTS != RECOVERY_PROVEN
RESTORE_SUCCESS != SAFE_RESUME
RESTORED_STATE != RESTORED_AUTHORITY
RECOVERY_ADAPTER_PASS != RECOVERY_DRILL_EXECUTED
```

Machine PASS checks represented recovery relations only. Locator existence, failure-domain independence, evidence authenticity, world reconciliation, and authority truth remain external/Host evidence.

See `../../../operational/HOW-MAP.md` (`OA-REC-01`) for Host alternatives and composition.
