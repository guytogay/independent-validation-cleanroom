# Contested Authorship — Specialized Optional Reference

Status: `v0.3.7 candidate.2 / SPECIALIZED_OPTIONAL_REFERENCE / DEFAULT_OFF / NOT_NORMATIVE_ONTOLOGY`

Use for material durable self-surface change where origin, endorsement, conflict, revision, or authority laundering can change the decision.

Ordinary task state, cache/index maintenance, episodic logging, and reversible formatting are normally `OUT_OF_SCOPE_FOR_CONTESTED_AUTHORSHIP`.

Bundled machine files reuse the selected research reference bytes. Hosts may map the property to Git revisions, state-store versions, proposal/diff/readback records, or other versioned durable-self mechanisms.

Key boundaries:

```text
DURABLE_SELF_CHANGE != ORDINARY_MEMORY_UPDATE
IMPORTED_OR_USER_ORIGIN != SELF_AUTHORED
SELF_AUTHORED != EXTERNAL_AUTHORITY
VALID_AUTHORSHIP_RECORD != BENEFICIAL_CHANGE
```

Machine PASS prevents represented origin/conflict/authority laundering. It does not prove sincere self-authorship, moral autonomy, beneficial evolution, or legitimate external mandate.

See `../../../operational/HOW-MAP.md` (`OA-AUTHOR-01`) for applicability and Host alternatives.
