# Evidence Dependency Map — Advanced Optional Reference

Status: `v0.3.7 candidate.2 / ADVANCED_OPTIONAL_REFERENCE / DEFAULT_OFF / NOT_NORMATIVE_ONTOLOGY`

Use for material corroboration when common causes among agreeing observations can change the interpretation of confidence.

Do not build dependency graphs for ordinary recurrence or low-risk work without decision value.

Bundled machine files reuse the selected research reference bytes. The map exposes known/unknown dependency dimensions; it intentionally does not compute a universal independence score.

Key boundaries:

```text
N_OBSERVATIONS != N_INDEPENDENT_SUPPORTS
NO_KNOWN_EDGE != INDEPENDENT
DIFFERENT_MODEL != INDEPENDENT
SAME_MODEL != ZERO_CORROBORATION_VALUE
```

Dependency edges preserve possible common causes; they do not prove causal dependence or erase recurrence value.

Machine PASS proves represented dependency consistency only.

See `../../../operational/HOW-MAP.md` (`OA-EVID-01`). Use this reference chiefly for `MATERIAL_CORROBORATION`; Evidence Envelope may point to it without absorbing it.
