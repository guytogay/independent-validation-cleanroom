# Evidence Envelope — Advanced Optional Reference

Status: `v0.3.7 candidate.2 / ADVANCED_OPTIONAL_REFERENCE / DEFAULT_OFF / NOT_NORMATIVE_ONTOLOGY`

Use when a material claim needs several evidence boundaries to remain explicit at once: support, applicability, provenance, witness, activation, projection, or scoped completeness.

Do not require the full envelope for trivial observations or claims that do not need those mechanisms.

Bundled machine files reuse the selected research reference bytes. The envelope is a carrier; it does not turn its fields into truths.

Key boundary:

```text
EVIDENCE_EXISTS
!= EVIDENCE_SUPPORTS_CLAIM
!= SUPPORT_APPLIES_NOW
!= WITNESS_IS_INDEPENDENT
!= CONFIGURED_MECHANISM_RAN
!= PROJECTION_PRESERVED_MATERIAL_INFORMATION
```

Machine PASS proves represented consistency only. Evidence truth, real witness independence, transfer-basis correctness, and semantic completeness remain external questions.

See `../../../operational/HOW-MAP.md` (`OA-EVID-01`). Use Evidence Dependency Map only when material corroboration/common causes make it useful.
